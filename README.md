# 日想観 — 阿字池に沈む夕日と鳳凰堂

鳳凰堂は東を向いて建ち、池の向こう、西に極楽浄土があることを表しています。
その西に沈む夕日を東岸から見た 21 秒を、ブラウザの three.js で描きました。

写真・動画・3D モデル・テクスチャ画像といった外部の素材は使っていません。
建物は [平等院鳳凰堂の作品（aiimpl/byodoin）](https://github.com/aiimpl/byodoin) を Python で組んだ立体で、
その夕日の光だけを Blender（Cycles）で計算して焼き付け、空・池・映り込み・きらめき・日輪は three.js のシェーダーで描いています。

焼き付けのデータは約 360MB あるので、リポジトリには入れていません。手元で `make bake` してから開きます。

> 建物は実測図ではなく、一般的な外観をもとにした作図です。

## できるもの

- 21 秒・1920×1080・30fps の動画（音つき）
  1. 水鏡：水面すれすれ。逆さの鳳凰堂を、吹き寄せのさざ波が崩してきらめきに変える
  2. 対岸：目の高さまで上がる。日は大屋根の真後ろにあり、屋根の縁と鳳凰だけが光る
  3. 中堂：前進だけでゆっくり寄る
  4. 日輪と鳳凰：東岸 160m から望遠 200mm。二羽の鳳凰の間に夕日が下り、大棟に乗る
  5. 残照：鏡のような池に、堂と木立と燃える空
- 音：秋の虫と池の音、笙・篳篥・りん・楽太鼓・梵鐘（NumPy で合成）
- ブラウザで開くページ（同じ場面を、その場で描く。焼き付けのデータを手元に作ってから）

## 確かめた数字

- 宇治（北緯 34.889°・東経 135.808°）の日の入りの方位：秋分（9/23）270.4°、9/28 268.1°、10/15 260.2° → 秋分のころ、夕日はほぼ真西に沈む
- 東岸 160m・目の高さ 3m から見た大棟の上端は仰角 3.51°、二羽の鳳凰の間は約 2.4°。視直径 0.53° の日輪がちょうど収まる
- 夕空の明るさ：太陽のそばで約 55、建物の正面は 1 以下（Cycles の値）。だから引きの画では建物は影絵になる

※ 実際の堂の軸が真東から何度振れているかは確かめていません。場面の太陽は真西に置いています。

## 動作環境

- ページ：WebGL2 が動くブラウザ（Chrome / Safari / Edge）
- 焼き付けと書き出し：macOS（Apple M5・メモリ 32GB で確認）、[Blender](https://www.blender.org/) 5.2、Python 3.11 以上、Google Chrome、ffmpeg

## 使い方

```sh
make setup     # Python の道具（numpy・scipy・pillow・playwright）
make scene     # 平等院鳳凰堂のシーンを組み立てる（aiimpl/byodoin を ../byodoin に）
make bake      # 夕日の光を焼き付ける → build/bake
make video     # 音と 630 コマ → build/nissokan.mp4（1 コマ約 0.8 秒、全体で約 9 分）
make serve     # http://127.0.0.1:8793/web/ で開く（?t=14 で 14 秒目から、?still で止める）
```

## しくみ

**光は Blender、描くのは three.js。**
平等院のシーンを最終コマの状態にし、東岸から見た夕日（真西、高さ 7° と 3.5° の 2 通り）と、同じ Cycles の夕空（多重散乱）で照らして焼き付けます（`bake/`）。
焼くのは拡散光（直接＋間接＋材質の色）、夕日の当たり、隅の暗さ。three.js では時刻に合わせて 2 通りを混ぜ、
見る向きで変わる光（金具の照り・瓦の艶・空の映り込み）と空気の霞だけを足します（`web/baked.js`）。

- 建物はテクスチャに焼きます。部材が接し合う作りなので、頂点に焼くと柱の端などが 0 になるためです。
  面を同じ密度で展開し（1 テクセル約 2.5cm、鳳凰の段は 8mm）、明るさは対数で 8bit に詰めます
- 地形と木は頂点に焼きます。木は種類ごとの原型を一度焼き（葉は逆光で透ける光も）、421 本は 1 本ずつ「樹冠に夕日が当たるか」を光線で調べて並べます
- 実物にない軒の釣灯籠（31 個）は外します。北の反橋と、東の池の中の庭石も外します（東岸からは、黒い板や塊が水の上に浮いて見えるため）

**夕空と日輪。** 焼き付けと同じ空を全天の表にして読み（`bake/sky.py`）、日輪だけ three.js で描きます。
視直径 0.53°、低いほど大気の屈折で縦につぶれ（3.5° で 0.86 倍）、周辺ほど暗く赤くなります（`web/sky.js`）。

**池。** 世界を上下反転して同じカメラで描いた画を、水面がさざ波の傾きでずらして読みます（映り込み）。
さざ波は風の向きに寄った 40 本の波で、吹き寄せの帯が風の速さ（5m/s）で池を渡るところだけ強くなります。
きらめきは、面を小さな区画に分け、区画ごとに乱れた傾きを振って、日輪を映す向きの区画だけを光らせます。
日輪が建物や木に隠れる所では光りません（`web/pond.js`）。

**仕上げ。** 縦横 2 倍で描いて縮め、1 コマを 1/60 秒の幅で 3 回に分けて平均します。明るすぎる所だけにじませ、周辺をわずかに暗くします（`web/main.js`）。

**時間割り。** カメラ・日の高さ・露出・吹き寄せは `web/shots.js` の 5 ショットの表です。日輪が大棟に触れる 17.5 秒に楽太鼓が鳴ります（`sound/compose.py`）。

## 構成

```
bake/
  common.py        焼くときの世界（夕日・夕空）、立体の下ごしらえ、焼き付けと書き出し
  bake_hall.py     鳳凰堂（テクスチャ）
  bake_env.py      地形・洲浜と庭石・木（頂点）
  sky.py           夕空の全天の表
web/
  index.html       ページ
  main.js          描画の流れ（映り込み・本描画・仕上げ）と書き出しの入口
  shots.js         5 ショットの時間割り
  baked.js         焼いた光で描く（建物・地形・木）
  sky.js           夕空と日輪
  pond.js          池（さざ波・吹き寄せ・映り込み・きらめき）
  vendor/three     three.js r160（MIT）
sound/
  instruments.py   雅楽風の楽器と効果音（aiimpl/byodoin の音から）
  compose.py       21 秒の音を組み立てる
tools/
  render.py        Chrome を開いて 1 コマずつ PNG に書き出す
  encode.sh        連番 PNG と音 → mp4（yuv420p）
  snap.py          ページを 1 枚撮る（確かめ用）
conte/             コンテ（CONTE.md）と、立体で撮った下絵
```
